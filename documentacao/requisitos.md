# Requisitos — Agenda de Tarefas


## Lista de requisitos funcionais 

| ID    | Nome                                           | Descrição                                                                                               |
| ----- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| RF-01 | Cadastrar o usuário          | O sistema deve permitir que o usuário seja cadastrado, armazenando o seu email, senha e nome.                               |
| RF-02 | Login do usuário         | O sistema deve permitir que o usuário realize seu login usando seus dados já cadastrados                             |
| RF-03 | Visualizar o calendário         | O sistema deve permitir que o usuário visualize o calendário com os seus alertas, lembretes e tarefas criados                            |
| RF-04 | Criar novos registros         | O sistema deve permitir que o usuário crie novos alertas, lembretes e tarefas                         |
| RF-05 | Personalizar os registros         | O sistema deve permitir que o usuário personalize o nome, descrição, cor, formato e a data e o horário dos registros                            |
| RF-06 | Editar os registros        | O sistema deve permitir que o usuário edite os registros que já foram previamente criados e personalizados                             |
| RF-07 | Compartilhar registro pré definidos         | O sistema deve permitir que o usuário compartilhe seus registros personalizados com outros usuários da plataforma                            |
| RF-08 | Utilizar registros pré definidos         | O sistema deve permitir que um usuário utilize os registros pré definidos de outros usuários que foram compartilhados                             |
| RF-09 | Emissão de alertas         | O sistema deve mostrar alertas no dispositivo do usuário com base na personalização fornecida pelo usuário dos registros                          |
| RF-10 | Disponibilizar configurações específicas         | O sistema deve disponibilizar tipos específicos de alertas e lembretes para o usuário usar                              |
| RF-11 | Organização do menu        | O sistema deve organizar as funções dentro de um menu em uma barra lateral                             |

## Lista de requisitos não funcionais 

| ID    | Nome                                           | Descrição                                                                                               |
| ----- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| RNF-01 | Interface eficiente         | O sistema deve apresentar uma interface simples e intuitiva ao usuário                               |
| RNF-02 | Usabilidade do aplicativo         | O sistema deve permitir que usuários sem experiência com aplicativos de agendas e usuário com experiencia consigam usar as funções                     |
| RNF-03 | Organização em menu         | O sistema deve organizar as funções da plataforma dentro de um menu em uma barra lateral                             |
| RNF-04 | Interface personalizável         | O sistema deve permitir que o usuário personalize certas partes da interface do programa                          |
| RNF-05 | Persistência de informações         | O sistema deve manter as informações e dados de cada usuário mantidas, mesmo após o fim da sessão                         |
