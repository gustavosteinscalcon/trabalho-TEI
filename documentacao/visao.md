# Visão do Projeto - Agenda de Tarefas


## 1. Problema a ser resolvido

* O problema que o projeto tenta tratar é a limitação da maioria dos aplicativos de agenda que muitas vezes não oferecem uma personalização muito boa, nem uma interface eficiente para o usuário, além de geralmente possuírem poucas funções, o que limita a experiência do usuário 
---

## 2. Funcionalidades do projeto

* O aplicativo permitirá o usuário criar alertas e lembretes dentro de um calendário, permitindo uma personalização ampla, como, por exemplo, o nome, descrição, cor, formato, som emitido, data, horário e também terá outras configurações padrões já definidas para funções específicas, como lembrete de ingestão de água e exercício físico. Além disso, o aplicativo permitirá diferentes usuários cadastrados compartilharem entre si suas configurações personalizadas para qualquer um poder fazer o uso também.

---

## 3. Público-Alvo

* Pessoas que precise gerenciar suas tarefas, afazeres ou hábitos e não tem familiarilidade com esse tipo de aplicativo.
* Usuários que já utilizam, com frequência ou esporadicamente aplicativos de agenda.
---

## 4. Proposta de valor

* Cadastro e login do usuário com persistências das informações registradas durante o uso
* Compartilhamento de agendas personalizadas pelos usuários
* Personalização ampla dos lembretes e alertas criados pelo usuário
* Funcionalidades separadas em um menu
* Personalização da interface do aplicativo
